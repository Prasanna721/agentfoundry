# Yoink Research Pack

Last updated: 2026-04-25

This folder captures the current reverse-engineering and hackathon research needed to rebuild Bakeoff/Yoink as an on-chain system on Arc.

Files:

- `01-bakeoff-reverse-engineering.md` - product model, API surface, hidden rules, and inferred system design
- `02-hackathon-requirements.md` - current hackathon constraints, tracks, required tech, judging, and submission checklist
- `03-onchain-parity-architecture.md` - recommended Arc/Circle design for an on-chain Yoink that still preserves Bakeoff's core behavior
- `sources.md` - source index with URLs and what each source was used for

Recommended reading order:

1. `02-hackathon-requirements.md`
2. `01-bakeoff-reverse-engineering.md`
3. `03-onchain-parity-architecture.md`
